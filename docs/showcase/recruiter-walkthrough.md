# Recruiter walkthrough (30–60 seconds)

CareerPilot is a local job-search workspace, not a bot that applies for you.

A candidate starts with a real resume. CareerPilot turns that into a profile it can actually cite — skills and jobs that showed up in the document, not invented ones. Discover stays locked until that profile is ready.

Then it finds roles and tells you **why** a listing matches: this skill is on the resume, that requirement is not, this one was never verified. Fit is a calculated score, not a vibe.

If you want to apply, it drafts bullets and a letter from that same evidence. Those stay drafts until you check eligibility and approve. If the resume or the posting changes, old drafts are treated as stale instead of quietly reused.

On Greenhouse and Lever, an unpacked Chrome extension can help fill the obvious fields. It does **not** fill demographic questions, it does **not** tick terms for you, and it does **not** press Submit. You still send the application.

After that, Track and Analytics only record what you actually did. They will not invent interviews or offers.

That is the product: grounded evidence, a score you can inspect, human approval, and a hard stop before Submit.
